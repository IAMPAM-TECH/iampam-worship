# S3 버킷 (hishalom-data) 구조 분석

## 버킷 정보
- **버킷 이름**: `hishalom-data`
- **리전**: `ap-northeast-2` (서울)
- **URL**: `https://hishalom-data.s3.ap-northeast-2.amazonaws.com`

## 최상위 폴더 구조

### 1. **christian-sermons/** (기독교 설교)
- **설명**: 기독교 설교 관련 콘텐츠
- **파일 유형**: PNG 이미지 파일들
- **구조**: 각 설교별로 폴더가 있고, 각 폴더 내에 `page_001.png`, `page_002.png` 등의 이미지 파일이 포함됨

### 2. **shorts/** (짧은 콘텐츠)
- **설명**: 짧은 형태의 콘텐츠
- **파일 유형**: 확인 필요

### 3. **transcribe/** (전사)
- **설명**: 전사(transcription) 관련 파일들
- **파일 유형**: 확인 필요

### 4. **찬송/** (찬송가)
- **설명**: 찬송가 관련 콘텐츠
- **파일 유형**: PNG 이미지 파일들
- **구조**: 
  - 각 찬송가별로 폴더가 있음 (예: "265장-주 예수님의 사랑의 교회", "292장-예수님의 사랑의 교회" 등)
  - 각 폴더 내에 `page_001.png`, `page_002.png` 등의 이미지 파일이 포함됨
  - 일부 찬송가는 여러 페이지로 구성됨 (예: 8-14페이지)

### 5. **교독/** (교독문)
- **설명**: 교독문 관련 콘텐츠
- **파일 유형**: PNG 이미지 파일들
- **구조**: 
  - 각 교독문별로 폴더가 있음
  - 각 폴더 내에 `page_001.png`, `page_002.png` 등의 이미지 파일이 포함됨

### 6. **성경/** (성경)
- **설명**: 성경 관련 콘텐츠
- **파일 유형**: PNG 이미지 파일들
- **구조**: 
  - 각 성경 구절별로 폴더가 있음
  - 각 폴더 내에 `page_001.png`, `page_002.png` 등의 이미지 파일이 포함됨

### 7. **찬송가/** (찬송가 MP3)
- **설명**: 찬송가 오디오 파일
- **파일 유형**: MP3 오디오 파일들
- **구조**: 
  - 각 찬송가별로 MP3 파일이 있음
  - 파일명 형식: `{번호}장-{제목}.mp3` (예: "1장-예수님의 사랑의 교회.mp3", "100장-예수님의 사랑의 교회.mp3" 등)
  - 1장부터 246장까지의 찬송가가 포함되어 있음

## 파일 유형별 분류

### PNG 이미지 파일
- **용도**: 찬송가, 교독문, 성경, 설교 등의 텍스트를 이미지로 변환한 파일
- **명명 규칙**: `page_XXX.png` (XXX는 페이지 번호, 001부터 시작)
- **크기**: 대략 700KB ~ 1.3MB 사이

### MP3 오디오 파일
- **용도**: 찬송가 오디오 파일
- **명명 규칙**: `{번호}장-{제목}.mp3`
- **크기**: 대략 600KB ~ 4.7MB 사이

## 주요 특징

1. **한글 파일명 사용**: 대부분의 폴더와 파일이 한글 이름을 사용하고 있음
2. **계층적 구조**: 각 콘텐츠 타입별로 최상위 폴더가 있고, 그 하위에 개별 콘텐츠 폴더가 있음
3. **이미지 기반 콘텐츠**: 찬송가, 교독문, 성경 등이 PNG 이미지로 저장되어 있음
4. **오디오 콘텐츠**: 찬송가 MP3 파일들이 별도 폴더에 저장되어 있음

## 참고사항

- 로컬 스토리지에는 '교독', '성경', '찬송' 타입의 콘텐츠만 저장되며, 나머지는 S3에서 직접 가져옴
- 각 콘텐츠는 페이지 단위로 이미지화되어 저장됨
- 찬송가는 이미지(PNG)와 오디오(MP3) 두 가지 형태로 모두 제공됨
